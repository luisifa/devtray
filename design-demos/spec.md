# devtray 交互改进：共同输入

桌面服务管理工具，Rust + PySide6；现有深松绿色导航、浅底工作区。用户需要明确的操作对象、可取消错误、可靠的 Agent 检测、资源清理选择清单。

交付：1440×900 的单文件交互 HTML 原型，每方向一份；同时适配 1040×720 和 375×812（移动端用于检查溢出，不代表推出移动客户端）。默认资源页，含项目／项目内容／待清理清单三列。三方向的结构必须不同，不允许只换颜色。

必做交互：项目切换；目录加入/移出右侧清单；选中总量与数量；清空清单；计划预览（演示确认，绝不调用真实清理）；错误关闭及托盘状态演示；导航 Agent/Skills、总览；两表右键菜单与键盘菜单入口；Skills 更新检查与 Agent 重新检测明确分开。复制检测放右键详情，不放主表。总览不出现启动当前项目/停止当前项目这两个按钮。

信息来源：data.json 为 2026-10-28 本机扫描缓存的真实快照；状态变更是演示，用可见标签说明。禁止编造服务在线数、新版本号、释放空间承诺。Agent 页可显示 executable 名与待重新检测，不伪造新版；Skills 示例项只能使用当前项目已有技能名。无后端调用，无安装、删除真实文件。

主角：实际的项目目录、占用数据与右侧清理清单。只用功能图标，避免把第三方字母包装成官方标志。devtray 标志沿用项目资产。

视觉容量：默认资源页在 900 高度中能看到至少 5 行。正文至少14px、标签至少12px；危险操作说明明确但不铺满警告。操作按钮适合鼠标点击，主要控件44px。

Form 五问：这是用户每天反复操作的工作台；观看距离是桌面显示器；温度因方向而异；高密度信息靠分区与行对齐；视觉母题来自目录的父子关系和清理选择。
